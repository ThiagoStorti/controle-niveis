💧 Controle de Níveis de Água

📌 Sobre o projeto
Sistema desenvolvido em Python para simular o monitoramento de um reservatório, exibindo mensagens coloridas conforme o nível da água.

📊 Níveis do reservatório
Nível / Situação / Cor
1 / Muito baixo (crítico) / Vermelho
2 / Baixo / Amarelo
3 / Médio / Verde
4 / Alto / Ciano
5 / Muito alto (alerta) / Azul

▶️ Como executar

Instale a dependência:
pip install colorama

Execute o programa:
python controle_agua.py
